# Software and Other Resources

## Software and libraries

_Practitioner tools listed by Wang et al. (TSE 2026). The survey notes that they are not research publications and leaves them out of its main corpus, but says they can serve as valuable infrastructure for monitoring and diagnosis in real-world deployments._

| Name | Description | Link |
|---|---|---|
| Langfuse | Listed as open source. Trace inspection, prompt and tool-call monitoring, evaluation, and workflow debugging. | [link](https://langfuse.com/) |
| Weave | Listed as open source, with the same capabilities as above. | [link](https://github.com/wandb/weave) |
| Arize Phoenix | Listed as open source, with the same capabilities as above. | [link](https://arize.com/phoenix/) |
| LangSmith | Commercial or hosted. Production-facing tracing, evaluation, and monitoring. | [link](https://www.langchain.com/langsmith/observability) |
| HoneyHive | Commercial or hosted. Production-facing tracing, evaluation, and monitoring. | [link](https://www.honeyhive.ai/) |
| Braintrust | Commercial or hosted. Production-facing tracing, evaluation, and monitoring. | [link](https://www.braintrust.dev/) |

## Benchmarks and evaluation frameworks

_Descriptions are based on Table 6 of Wang et al. (TSE 2026)._

| Name | Description | Link |
|---|---|---|
| Who&When | Annotated with the failure-responsible agent, the faulty step, and some root causes. The benchmark used by almost all failure attribution studies. | _to add_ |
| TraceElephant | 220 failure traces with full execution data and reproducible environments. Annotated with the responsible agent and faulty step. | [link](https://github.com/TraceElephant/TraceElephant) |
| AgentRx | 115 failed trajectories from τ-bench, Flash, and Magentic-One. Marks the first unrecoverable failure and its root cause. | [link](https://arxiv.org/abs/2602.02475) |
